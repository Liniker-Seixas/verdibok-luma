# verdibok-luma

Public OAuth client ID metadata document for Verdibok's "Sign in with Luma" (Luma's MCP server uses Client ID Metadata Documents instead of client secrets).

Served at https://liniker-seixas.github.io/verdibok-luma/client.json. It contains no secrets: only the client name and the addresses Luma may send the sign-in back to.
